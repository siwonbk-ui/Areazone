# NAT CAT Zoning (Updated)

แผนที่ระดับความเสี่ยงภัยธรรมชาติของประเทศไทย ระดับจังหวัด/อำเภอ แสดงผลเป็นเว็บเพจแบบ static
(เปิดจากไฟล์ได้โดยตรง ไม่ต้องใช้เซิร์ฟเวอร์หรือฐานข้อมูล)

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ หรือเปิดใช้งาน GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**

## ไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (HTML/CSS/JS ในไฟล์เดียว) |
| `data_updated.js` | ข้อมูลระดับความเสี่ยงรายอำเภอ 1,212 รายการ พร้อมตัวเลขดิบที่ใช้จัดชั้น |
| `map_paths.js` | ขอบเขตแผนที่ 77 จังหวัด (SVG path) |

ต้องวางไฟล์ทั้ง 3 ไว้ในโฟลเดอร์เดียวกันเสมอ

## ความสามารถ

- แผนที่ประเทศไทยระบายสีตามระดับความเสี่ยง พร้อมชื่อจังหวัดกำกับ
- กรองตามภัย 6 ประเภท: แผ่นดินไหว · ลูกเห็บ · วาตภัย · น้ำท่วม · ภัยแล้ง · ดินโคลนถล่ม
- กรองตามภาค (6 ภาค) พร้อมซูมแผนที่อัตโนมัติ และปุ่มล้างตัวกรอง
- คลิกจังหวัดเพื่อดูรายละเอียดรายอำเภอ พร้อมตัวเลขดิบที่ใช้ตัดสินระดับความเสี่ยง
- ค้นหาด้วยชื่อจังหวัด/อำเภอ/รหัสไปรษณีย์
- สลับโหมดสว่าง–มืด และรองรับการใช้งานบนมือถือ

## แหล่งข้อมูล

ข้อมูลทั้งหมดมาจากชุดข้อมูลเปิดของหน่วยงานราชการไทย

| ภัย | แหล่งข้อมูล | ข้อมูล ณ |
|---|---|---|
| แผ่นดินไหว | กฎกระทรวงกำหนดการรับน้ำหนักฯ ในการต้านทานแรงสั่นสะเทือนของแผ่นดินไหว พ.ศ. 2564 | 4 มี.ค. 2564 |
| น้ำท่วม | กรมพัฒนาที่ดิน — พื้นที่น้ำท่วมซ้ำซาก **ร่วมกับ** ปภ. — สถิติรายปีการเกิดอุทกภัย | LDD ถึงปี 2568 · ปภ. 2562–2567 |
| ภัยแล้ง | กรมพัฒนาที่ดิน — พื้นที่แล้งซ้ำซาก | ถึงปี 2567 |
| วาตภัย | กรมป้องกันและบรรเทาสาธารณภัย — สถิติรายปีการเกิดวาตภัย | 2562–2567 |
| ลูกเห็บ | ปภ. — สถิติวาตภัยเฉพาะเหตุ "พายุฤดูร้อน" ช่วง ก.พ.–พ.ค. (ใช้เป็นตัวแทน) | 2562–2567 |
| ดินโคลนถล่ม | ปภ. — สถิติรายปีการเกิดดินโคลนถล่ม | 2562–2567 |

รายละเอียดที่มา วิธีจัดชั้นความเสี่ยง และลิงก์ต้นทางของแต่ละภัย ดูได้จากปุ่ม **"แหล่งข้อมูล"** ในหน้าเว็บ

## ข้อจำกัดและข้อควรทราบ

- ชั้นข้อมูล **แผ่นดินไหว** เป็นระดับ **จังหวัด** เท่านั้น ตามที่กฎกระทรวงกำหนด (34 จังหวัดนอกพื้นที่ควบคุมจะไม่มีสี)
- ชั้นข้อมูล **ลูกเห็บ** ไม่มีชุดข้อมูลโดยตรง จึงใช้สถิติ "พายุฤดูร้อน" เป็นตัวแทน ควรถือเป็นค่าประมาณ
- **เกณฑ์แบ่งระดับสี (threshold) กำหนดขึ้นจากการกระจายตัวทางสถิติของข้อมูล ไม่ใช่เกณฑ์ทางการของหน่วยงาน**
- สีขาว/ไม่มีสี หมายถึง "ไม่พบข้อมูลในชุดข้อมูลอ้างอิง" ไม่ได้แปลว่าพื้นที่นั้นไม่มีความเสี่ยง
- ชั้นข้อมูล **น้ำท่วม** ใช้ระดับที่สูงกว่าระหว่างพื้นที่น้ำท่วมซ้ำซาก (LDD) กับสถิติเหตุการณ์จริง (ปภ. 2562–2567)
  โดยข้อมูล LDD หลายจังหวัดยังเป็นปีวิเคราะห์ 2564 และครอบคลุมเฉพาะพื้นที่เกษตร จึงอาจต่ำกว่าสถานการณ์จริงในพื้นที่ที่เพิ่งเกิดน้ำท่วมใหญ่
- สถิติอุทกภัยปี 2568 ของ ปภ. เผยแพร่เฉพาะ**ระดับจังหวัด** จึงแสดงเป็นข้อมูลประกอบในหน้าเว็บ ไม่ได้นำมาคิดสีรายอำเภอ
- เอกสารและเว็บเพจนี้จัดทำโดยใช้ AI ช่วยรวบรวมและประมวลผลข้อมูลเปิด **ไม่ใช่เอกสารทางการของหน่วยงานใด**
  ควรให้ผู้รับผิดชอบตรวจสอบก่อนนำไปใช้ประกอบการตัดสินใจ
