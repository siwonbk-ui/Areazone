# NAT CAT v2 — ตรวจผลรายวัน

Import `natcat-daily-update.json` เข้า n8n แล้วปิด workflow เวอร์ชันเดิม

- ทำงานทุกวันเวลา **07:00 Asia/Bangkok**
- อ่าน `pipeline/update_status.json` จาก GitHub (ต้องเผยแพร่ไฟล์นี้ก่อน)
- ลองใหม่เมื่ออ่านไม่สำเร็จ 3 ครั้ง และสรุปว่าให้ตรวจระบบเมื่อข้อมูลล่าช้าเกิน 4 ชั่วโมง
- แจ้งสถานะ baseline, แหล่งข้อมูลปัจจุบัน และจำนวนรายการสีที่รอตรวจ
- ผลข้อความอยู่ใน `text`; สถานะต้องดูแลอยู่ใน `needsAttention`
- ไม่ต้องใช้ PAT หรือ AI สำหรับ public repo
- โหนดปลายทางยังเป็น noOp ให้ต่อช่องทางแจ้งเตือนก่อนเปิดใช้งาน หากยังไม่ต่อ ดูผลจาก execution ได้
- ไฟล์นำเข้าตั้ง `active=false` เพื่อให้ทดสอบก่อนเปิดใช้งานจริง

GitHub เป็นผู้ตรวจข้อมูลประวัติวันละครั้งและรวบรวมรายงานปัจจุบันตามรอบ feed จึงไม่ต้องให้ n8n ตรวจ metadata หรือสั่ง rebuild ซ้ำ
